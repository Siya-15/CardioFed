# Data

`raw/processed.{cleveland,hungarian,switzerland,va}.data` are the four "processed" files of the
**UCI Heart Disease** dataset (14 attributes, `?` = missing), committed so the project runs offline.

* Source: https://archive.ics.uci.edu/dataset/45/heart+disease
* Creators: Andras Janosi (Hungarian Institute of Cardiology, Budapest), William Steinbrunn (University Hospital Zurich),
  Matthias Pfisterer (University Hospital Basel), Robert Detrano (V.A. Medical Center Long Beach and Cleveland Clinic Foundation)
* License: CC BY 4.0. Citation: Janosi, A., Steinbrunn, W., Pfisterer, M., & Detrano, R. (1988). Heart Disease [Dataset].
  UCI Machine Learning Repository. https://doi.org/10.24432/C52P4X

Re-download and verify row counts (303 / 294 / 123 / 200): `python -m cardiofed.data download --force`

`processed/heart_clean.csv` is generated by `python -m cardiofed.data clean` (not committed).
